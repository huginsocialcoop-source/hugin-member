# 카카오 채널 데이터 수집기 (kakao-sync)

허그인 대시보드의 **카카오 채널 현황** 페이지를 실제 데이터로 연동하는 수집기입니다.
대시보드가 이 서버를 통해 실시간 데이터를 읽고, 연동 전에는 샘플 데이터로 표시됩니다.

## ⚠️ 먼저 알아두기: 카카오의 공식 제한

**카카오는 채널 전체 통계(친구 수 증감 추이, 게시물 도달·반응)의 공개 API를 제공하지 않습니다.**
카카오 데브톡에서 카카오가 공식 확인한 사항입니다 (2026-08: [카카오 채널 인사이트 API 신청 답변](https://devtalk.kakao.com/t/api/150998)).

공식 API가 실제로 제공하는 것은:
1. **카카오톡 채널 웹훅** — 사용자가 채널을 **추가(added)/차단(blocked)** 하는 이벤트를 실시간으로 우리 서버에 전송 ([공식 문서](https://developers.kakao.com/docs/ko/kakaotalk-channel/callback))
2. **채널 관계 조회** — 특정 서비스 회원과 채널의 친구 관계 확인
3. **고객파일 관리** — 광고 타겟용 고객 그룹 관리

이 수집기는 이를 조합해 추이 데이터를 **자체 구축**합니다:

| 계층 | 방법 | 채워지는 데이터 |
|---|---|---|
| 실시간 | 웹훅 수신 | 일별 추가·차단 수 (자동, 계속 축적) |
| 백필 | 파트너센터 통계 CSV 업로드 | 과거 일별 추이 전체 |
| 기준값 | 현재 친구 수 1회 입력 | 전체 친구 수 (이후 자동 가감) |

게시물 도달·반응 통계는 API가 없어 `data/manual.json`에 직접 기록하면 대시보드에 반영됩니다 (아래 "게시물 성과" 참고).

## 빠른 시작 (5분)

```bash
# 1. 폴더 구성 — server.js와 대시보드를 같은 폴더(또는 부모 폴더)에 둔다
kakao-sync/server.js  ←  이 파일
huggin-dashboard.html ←  대시보드

# 2. 실행 (Node.js 18+ 필요, 외부 의존성 없음)
node server.js

# 3. 브라우저에서
#    대시보드  http://localhost:8787/
#    관리      http://localhost:8787/admin  ← 여기서 기준값·CSV·설정
```

관리 페이지에서:
1. **기준 친구 수 입력** — 파트너센터 통계에서 오늘의 친구 수를 확인해 입력
2. **CSV 백필(선택)** — 파트너센터 > 통계 > 친구 통계를 엑셀로 내려받아 CSV로 저장 후 업로드하면 과거 추이가 한 번에 채워짐 (날짜·친구수·신규·차단 열을 자동 인식)
3. 끝 — 대시보드 카카오 탭 배지가 "API 연동"으로 바뀌면 성공

## 카카오 로그인 연결 테스트 (공식 API 실호환 확인)

관리 페이지의 **설정 · 연결 테스트** 카드에서:
1. 앱의 **REST API 키**를 입력하고 설정 저장
2. **[카카오 로그인으로 연결 테스트]** 클릭 → 카카오 승인 화면(plusfriends 동의) → 채널 관계 조회 API(`GET /v2/api/talk/channels`) 호출 결과 표시

이 테스트가 성공하면 앱-카카오 연동이 정상입니다. 조회되는 것은 **동의한 사용자 개인**의 채널 관계(친구/차단/추가 시각)이며, 채널 전체 통계는 이 API에 포함되지 않습니다(위 제한 참고).

### 연결 테스트 오류 해결 표

관리 페이지 "현황" 카드에 **마지막 연결 시도** 기록이 남습니다. 대표 오류와 해결:

| 오류 원문에 포함된 것 | 원인 | 해결 |
|---|---|---|
| `redirect` | Redirect URI 불일치/미등록 | [앱] > [플랫폼 키] > [카카오 로그인 리다이렉트 URI]에 `/oauth/callback` 전체 주소를 정확히 등록 |
| `활성`, `disable` | 카카오 로그인 미사용 설정 | [카카오 로그인] > [사용 설정] ON |
| `secret`, `KOE101` | 앱에서 클라이언트 시크릿 활성화 | 관리 페이지 설정의 클라이언트 시크릿 입력란에 코드 저장 (또는 앱에서 시크릿 OFF) |
| `scope`, `-402`, `동의` | plusfriends 동의항목 미설정 | [카카오 로그인] > [동의항목] > "카카오톡 채널 추가 상태 및 내역" 추가 |
| `invalid_grant` | 승인 코드 1회성 사용 | 연결 테스트 버튼 다시 클릭 |
| `channel`, 목록 0건 | 앱-채널 연결(심사) 전 | [앱] > [카카오톡 채널] 연결 상태 확인, 대표 채널 설정 |

## 카카오 디벨로퍼스 설정 (웹훅 연결, 1회)

웹훅을 받으려면 앱-채널 연결 심사가 필요합니다 (영업일 3~5일, 1회만 하면 됩니다).

1. [developers.kakao.com](https://developers.kakao.com)에서 **앱 생성** → 카카오 로그인 **사용 설정 ON**
2. 내 앱 > 카카오 로그인 > **Redirect URI** 등록: `http://localhost:8787/oauth/callback` (서버 주소가 다르면 그 주소)
3. 내 앱 > **동의항목**에서 `plusfriends`(카카오톡 채널 추가 상태 및 내역) 추가
4. 채널을 **비즈니스 채널**로 전환하고(파트너센터 > 비즈니스 심사), 앱 > 추가 기능 신청 > **[카카오톡 채널 연결]** 신청 → 심사 후 연결
5. 내 앱 > 웹훅 > **[카카오톡 채널 웹훅]**에 등록:
   - 인터넷에서 접근 가능한 공개 주소 필요 → 예: 터널 사용
     ```bash
     npx localtunnel --port 8787   # 또는 ngrok http 8787, 또는 사무실 서버/클라우드 호스팅
     ```
   - 등록 URL: `https://<공개주소>/webhook/kakao`
6. (강력 권장) 관리 페이지의 **설정**에서 카카오 **대표 어드민 키**를 저장 → 웹훅 요청 위조 방지 검증 켜짐

> 조합원·이용자가 카카오톡 앱에서 채널을 추가/차단할 때마다 이벤트가 수집기로 자동 들어옵니다.

## 완전 자동 — 로그인·다운로드까지 (nanum-auto)

해피나눔 로그인 → 조합원 파일 다운로드 → 집계 → 대시보드 반영까지 **명령 한 번**으로 수행합니다.

```bash
# 1. 자격 증명 저장 (최초 1회) — 이 파일은 그대로 PC에만 존재, 채팅·메일로 전송 금지
#    data/nanum-credentials.json  →  { "id": "아이디", "password": "비밀번호" }

# 2. 실행
node nanum-auto.js            # 로그인 → 전체기간 다운로드 → 자동 집계 → 대시보드 반영
node nanum-auto.js --probe    # 문제 진단용: 로그인·화면 구조만 확인 (debug/ 폴더에 화면 저장)

# 3. 매주 자동 실행 예약 (Windows, 매주 목요일 17:00)
schtasks /create /tn "허그인 주간자동화" /tr "node C:\경로\kakao-sync\nanum-auto.js" /sc weekly /d THU /st 17:00
#   macOS/Linux:  0 17 * * 4 node /경로/kakao-sync/nanum-auto.js
```

- 로그인 폼 필드명·다운로드 링크를 실행 시점에 자동 인식합니다(사이트 개편에도 유지되도록).
- 실패 시 `nanum-weekly/debug/`에 화면 원본이 저장됩니다 — `login-page.html`(로그인 폼 구조), `download-page.html`(다운로드 메뉴), `download-response.bin`(응답)을 공유하면 그 구조에 맞춰 즉시 수정해 드립니다.
- 다운로드 링크가 고정돼 있다면 자격 증명 파일에 `"downloadUrl": "..."`을 넣어 강제 지정할 수도 있습니다.
- **보안**: `nanum-credentials.json`은 사무실 PC에만 두고, 공유 폴더·백업·채팅에 올리지 마세요. 주기적 비밀번호 변경 시 파일만 갱신하면 됩니다.

## 주간 자동화 — 조합원 통계 자동 갱신

**매주 3분 루틴**: ① [해피나눔 > 조합원 정보 다운로드](https://www.ihappynanum.com/Nanum/nanum/user/extra/dataDownload)에서 파일 받기 → ② `nanum-weekly/` 폴더에 저장 → ③ 자동 업로드·집계·대시보드 반영

```bash
node nanum-weekly.js        # nanum-weekly/ 폴더의 최신 엑셀·CSV를 찾아 자동 집계·반영
node nanum-weekly.js --check
```

- 파일(엑셀 .xlsx / CSV)을 열 이름(가입일·생년월일·성별·주소·탈퇴일)을 자동 인식해 연령대·성별·지역·최근 12개월 증감으로 집계합니다. 인식 결과는 관리 페이지 업로드 후 안내에 표시됩니다.
- 매주 예약 실행 (파일만 폴더에 넣어두면 되는 구조):
  - **Windows**: 작업 스케줄러에 `nanum-weekly.bat` 등록, 또는
    `schtasks /create /tn "허그인 주간집계" /tr "node C:\경로\kakao-sync\nanum-weekly.js" /sc weekly /d THU /st 17:00`
  - **macOS/Linux(cron)**: `0 17 * * 4 node /경로/kakao-sync/nanum-weekly.js`
  - 예약 시간에 폴더에 파일이 없으면 로그에 안내만 남기고 넘어갑니다 (`nanum-weekly.log`).
- 완전 무인 자동화(시스템 로그인 자동화)는 해피나눔이 스크립트 로그인을 차단할 수 있어 미포함입니다 — 주간 다운로드만 수동으로 하고 집계·반영은 전부 자동인 구조입니다.
- 또는 수집기 관리 페이지(/admin)의 **[4 · 조합원 파일 업로드]**에서 파일만 올려도 동일하게 반영됩니다.

## 업로드 파일 헤더 형식 (자동 인식 기준)

관리 페이지 두 업로드 슬롯 모두 **CSV / .xlsx / .xls** 를 그대로 받습니다(구형 .xls는 서버가 자동 변환).

### ① 친구 통계 백필 (카카오 통계 리포트 → 일별 추이)
| 헤더에 포함되면 | 인식 |
|---|---|
| 날짜 · 일자 · date | 날짜 (필수) |
| 친구수 · 누적 친구 수 (단, 신규/추가/채팅/요청/차단 단어 없이) | 그날의 친구 수 → 마지막 유효값이 기준값 자동 설정 |
| 신규 · 추가 · 가입 · 유입 (예: "채널 추가수 합계") | 신규 |
| 차단 · 이탈 · 탈퇴 · 거부 | 이탈 — 없으면 전일 대비 감소분을 자동 역산 |
| 증감 · 순증감 | 순증감 (신규 열이 없을 때 신규로 사용) |

실제 파트너센터 파일 헤더 `날짜, 친구수, 채널 추가수 합계, 채팅 요청 친구수` → 그대로 인식됩니다.

### ② 추가 통계 (메시지 성과 · 친구 구성)
긴 형식(한 줄에 하나)과 넓은 형식(열이 날짜)을 모두 자동 인식합니다.
```
구분,항목,값           ← 구성 통계 예
성별,여성,461
연령대,40대,187
지역,운정,147
관심,아동 돌봄 프로그램,212

날짜,제목,발송수,클릭수   ← 메시지 성과 예 (긴 형식)
2026-09-12,조합원 4기 모집,2100,312
```
구분값: `성별` / `연령` / `지역·거주` / `관심·자녀·취향·프로그램` / 메시지 행(날짜+제목+발송+클릭). 열이 날짜로 가득한 넓은 형식(행=발송/클릭, 열=주차)도 주간 발송·클릭 추이로 자동 묶입니다.

## 파트너센터 통계 자동 수집 (kakao-channel-auto) — 세션 유지 반자동

파트너센터(카카오 채널 관리자)에 **한 번 로그인한 세션을 Chrome 프로필로 유지**해, 매주 통계 리포트를 자동으로 내려받아 집계·반영합니다.

```bash
# 1. 사전 설치 (1회) — Chrome 필요
cd kakao-sync && npm init -y && npm install puppeteer-core

# 2. 최초 1회: 눈으로 보는 로그인 (기기 인증 직접 처리, 세션 저장)
node kakao-channel-auto.js --login

# 3. 이후 무인 실행 (예약 등록 가능)
node kakao-channel-auto.js
```

**조합 PC 통합 설치 (권장)** — `setup-windows.bat` 더블클릭 한 번으로 위 과정 + 예약 등록까지:
- 매주 **목요일 17:00** 카카오 채널 통계 수집
- 매주 **목요일 17:30** 해피나눔 조합원 수집 (최초 1회 `node nanum-auto.js`로 자격 증명 입력)
- **놓친 실행 자동 보정**: PC가 꺼져 있어 예약을 놓쳤으면 다음 켜짐 즉시 실행 (StartWhenAvailable, tasks/*.xml)
- 수집기 서버 상주 등록(로그온 시 자동 시작) 포함

- 세션이 만료되면 창이 열려 재로그인만 하면 계속됩니다(주기 수 주~수개월).
- 다운로드 버튼을 텍스트(내려받기/다운로드/Excel)로 찾습니다 — 화면 개편 시 `--debug` 실행 → `debug-friend-page.png` 를 공유하면 셀렉터를 맞춰 드립니다.
- 다운로드한 파일은 `nanum-weekly/`에 저장되고 곧바로 집계·대시보드 반영까지 자동 진행됩니다.
- **주의**: 자동 로그인(아이디·비밀번호 스크립트 입력)은 하지 않습니다 — 카카오 계정 보안 절차와 제한 위험 때문이며, 이 방식(세션 유지)이 안전한 최대치의 자동화입니다. 채널 관리 계정에 이상 징후가 보이면 자동화를 중단하세요.

## 데이터 파일 (kakao-sync/data/)

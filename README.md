# 허그인 회원 통계 자동화

허그인사회적협동조합 운영 대시보드 + 카카오 채널·해피나눔 주간 자동 수집.

## 구성
- `index.html` — 대시보드 (메인 요약 / 카카오 채널 리포트·친구·메시지·방문·친구 구성 / 조합원 분석)
- `허그인 회원 통계 자동화/` — 자동화 전체 (수집기 서버, 주간 수집 스크립트, Windows 예약 파일, 설치 가이드)
- `설치-미리보기.html` — 설치 전 미리보기 문서

## 빠른 시작 (조합 PC)
1. `허그인 회원 통계 자동화/kakao-sync/setup-windows.bat` 실행 (Node.js·Chrome 필요)
2. 안내에 따라 해피나눔 자격 증명 + 파트너센터 로그인 (각 1회)
3. 매주 목요일 17:00 카카오 / 17:30 해피나눔 자동 수집 → 대시보드 자동 반영
4. 대시보드: http://localhost:8787

## 참고
- 이 Pages 버전은 데모 뷰(샘플 데이터)입니다 — 실데이터는 조합 PC의 수집기 서버(localhost:8787)에서 표시됩니다.
- 카카오는 채널 전체 통계의 공개 API가 없어, 리포트 파일 수집(주간) + 웹훅(실시간, 심사 후) 구조로 운영합니다.

> **시크릿 안내:** 이 저장소의 `kakao-sync/data/config.json` 키 값은 모두 `CHANGE_ME_*` 플레이스홀더입니다. 실제 운영 PC에서는 발급받은 값으로 채워 사용하고, 공개 저장소에는 실제 키를 올리지 마세요.

## 자동 갱신 안내

이 저장소의 `index.html`은 조합 PC의 수집기가 **매주 목요일 18:00** 주간 실데이터로 자동 발행합니다. 커밋 히스토리가 곧 주간 통계 로그입니다. 실시간 운영 화면은 조합 PC `http://localhost:8787`입니다.

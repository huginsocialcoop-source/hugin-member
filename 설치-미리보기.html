허그인 대시보드 · 설치 전 미리보기

조합 PC에 설치되는 주간 자동화의 전체 모습입니다. huggin-auto.zip 압축 해제 → kakao-sync\setup-windows.bat 실행 한 번으로 아래 상태가 됩니다.

Schedule

매주 목요일 — 이렇게 돌아갑니다

목 17:00
카카오 채널 통계 수집
파트너센터에 저장된 세션으로 친구 통계 리포트 자동 다운로드 → 수집기 집계 → 대시보드 반영
목 17:30
해피나눔 조합원 수집
해피나눔 자동 로그인 → 조합원 전체 파일 다운로드 → 연령·성별·지역·증감 자동 집계 → 반영
PC 꺼짐 보정

목요일에 PC가 꺼져 있어도, 다음에 켜지는 순간 두 수집이 순서대로 자동 실행됩니다 (StartWhenAvailable)
상시
수집기 서버 상주
부팅/로그온 시 자동 시작 — 브라우저에서 http://localhost:8787 로 항상 최신 대시보드 확인
Setup

설치 절차 (setup-windows.bat가 전부 자동)

huggin-auto.zip 압축 해제 — 예: C:\huggin (Node.js 미설치 시 nodejs.org LTS 먼저 설치)
해피나눔 자격 증명 입력 — 설치 중 입력창이 뜨면 아이디·비밀번호 입력. data\nanum-credentials.json에만 저장되고 이후 매주 무인 로그인에 사용
파트너센터 로그인 1회 — Chrome 창이 열리면 로그인(기기 인증 포함). 세션이 .kakao-profile\에 저장되어 이후 무인
예약 등록 — 목 17:00 카카오 / 목 17:30 해피나눔 / 부팅 시 수집기 — 3건이 Windows 작업 스케줄러에 등록됨
Check

점검 스크립트 (신규)

예약이 실제로 실행됐는지 확인하려면 명령창에서:

node check-status.js

출력 예시 (PC 설치 후 정상 상태):

✔ 카카오 채널 (목 17:00): 예약 있음 · 마지막 결과 코드 0(성공)
✔ 해피나눔 (목 17:30): 예약 있음 · 마지막 결과 코드 0(성공)
✔ 수집기 정상 · 채널 친구 738명 · 일별 90일치
✔ 카카오 리포트 마지막 반영: 2026. 10. 1. 17:00 (90일치)
✔ 조합원 파일 반영: 총 1,248명
✔ 해피나눔 자격 증명 저장됨
⚠ 웹훅 미연결 — 주간 리포트 방식으로 운영 중
Trouble

자주 묻는 문제

npm 설치 실패인터넷 연결·사내 방화벽 확인 후 재실행
Chrome 창 안 열림Chrome 설치 확인. 특수 경로면 CHROME_PATH 지정
해피나눔 로그인 실패비밀번호 변경했는지 확인 — node nanum-auto.js 재실행으로 재입력
화면 개편으로 수집 실패node kakao-channel-auto.js --debug → 생성된 캡처 파일 공유
예약이 실행 안 된 듯함node check-status.js 의 "마지막 결과 코드" 확인 — 0이면 성공
Security

보안 유의

자격 증명 파일 취급 — data\nanum-credentials.json(해피나눔)과 .kakao-profile\(파트너센터 세션)은 이 PC에만 존재해야 합니다. 이메일·공유폴더·채팅으로 전송 금지. 해피나눔 비밀번호를 변경하면 node nanum-auto.js 재실행으로 새 값만 입력하면 됩니다.
